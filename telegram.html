Telegram Bot API

Send a message

Write to a Telegram chat without leaving your browser. Credentials are used for this request only and are never stored by this page.

Get this from BotFather. Keep it private and do not use a shared computer.
Use @userinfobot or your bot's updates to find the destination chat ID.
Telegram accepts up to 4,096 characters in a text message.

Before sending

This page calls Telegram directly from your browser. It does not send your token to this website or save it in local storage. Revoke a token with BotFather if it is ever exposed.
